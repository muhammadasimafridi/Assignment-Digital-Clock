# Assignment-Digital-Clock
# 🕒 Digital Clock App

A simple and real-time **Digital Clock Web App** built using HTML, CSS, and JavaScript. This app displays the current time and updates automatically every second without requiring a page refresh.

---

## 🚀 Features

* ⏱️ **Real-Time Clock** – Displays current time (hours, minutes, seconds)
* 🔄 **Auto Update** – Refreshes every second dynamically
* 🎯 **Formatted Output** – Shows time in a clean `HH:MM:SS` format
* ⚡ **Instant UI Update** – No page reload required

---

## 🧠 Concepts Used

* DOM Manipulation
* JavaScript Date Object
* setInterval (timing functions)
* Dynamic Content Updating

---

## 📂 Project Structure

* `HTML` → Structure of the clock
* `CSS` → Styling and layout
* `JavaScript` → Logic for fetching and updating time

---

## 🎯 How It Works

1. The app retrieves the current time using JavaScript
2. Extracts:

   * Hours
   * Minutes
   * Seconds
3. Formats values (adds leading zero if needed)
4. Displays time in `HH:MM:SS` format
5. Updates every second automatically
